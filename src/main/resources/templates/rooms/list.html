안정성과 QA

비공개 채팅 전달, 실시간 방 상태 처리와 세 가지 QA 프로필을 정비했습니다.

0.5.0-alpha

경험치·로비 동기화·채널 버그 수정

프로필 XP와 상단 레벨을 갱신하고 로비 실시간 카드 경로를 최적화했으며, 게임 중 사망자 채널 표시 버그를 수정했습니다.

경험치와 레벨

  • 승리 시 500 XP, 패배 시 100 XP를 기록하며 완료 게임 ID로 중복 반영을 막습니다. 1,000 XP마다 레벨이 오릅니다.
  • 프로필에 총 게임·승리·패배·레벨/XP를 표시하고 경험치 진행 막대와 다음 레벨까지 필요한 XP를 안내합니다. 새 계정은 1,000 XP, Lv. 1에서 시작합니다.
  • 게임 종료, 공통 헤더가 있는 화면의 진입, 브라우저 화면 복원 때 최신 레벨을 다시 읽습니다. 상단 메뉴와 사용자 메뉴가 함께 바뀌며 조회 실패 시 기존 값은 유지합니다.

로비 목록 최적화

  • 방 목록 SQL에서 참가자별 COUNT 집계를 제거하고, 방 메타데이터와 메모리의 실시간 인원 정보를 결합합니다.
  • 인원·온라인 수가 바뀐 경우에만 로비 인원 메시지를 보냅니다. 최초 스냅샷은 유지해 새 구독자의 화면을 동기화합니다.
  • 목록에 없는 새 방은 전체 페이지 대신 Thymeleaf 카드 한 장을 요청해 삽입합니다. 검색·필터·번호를 다시 계산하며, 삭제되었거나 빈 방의 오래된 카드는 버립니다.
  • DB 입장 조회·빈 방 삭제를 공용 쓰기 잠금 밖으로 옮기고 재검증 경계를 추가했습니다. 유지보수 작업자 2개와 로비 전송 전용 작업자 1개로 대기열을 분리했습니다.
  • 방 생성·설정 변경의 최대 인원 및 비밀번호 검증을 공통 함수로 모았습니다. 이 정리와 작업자 분리의 개별 속도 효과는 따로 측정하지 않았습니다.

측정 결과와 주의점

  • 준비 상태 변경 320건에서 인원이 유지된 구간의 로비 구독자 알림은 640건·121,456B에서 0건·0B로 줄었습니다.
  • 4명 동시 준비 변경 묶음은 p50 3.6131ms→1.1050ms, p95 6.0234ms→2.0567ms로 측정됐습니다. 처리량은 899.5→2,340.8건/초였습니다. 여러 실시간 경로 변경을 함께 반영한 1회 로컬 측정입니다.
  • 전체 방 목록 HTML은 1,027,013B에서 1,025,151B(0.18% 감소)였습니다. 새 방 이벤트의 카드 한 장 응답은 906B입니다. 요청 범위가 달라 동일 작업의 전후 응답 크기 비교는 아닙니다.
  • 전체 목록 응답 지연이 모든 측정에서 개선된 것은 아닙니다. 동시성 8의 p50/p95는 134.62/159.69ms에서 141.17/167.37ms로 측정됐습니다. 수치는 2026-09-28, 방 1,000개·참가 기록 4,000개를 둔 로컬 환경에 한정합니다.

버그 수정: 채널 표시·화면 정리·QA

  • 게임 중 사망자에게 전체 채널이 표시되고 실제 권한과 화면 선택이 어긋나던 버그를 수정했습니다. 사망자 채널만 보이고 선택되며, 게임 종료 뒤에는 생존 여부와 관계없이 모두 전체 채널만 이용합니다.
  • 마피아·사망자 채팅의 공통 발송 경로와 수신자 선택을 정리했습니다. 연결되지 않은 초대·친구 버튼과 샘플 최근 게임·배지 영역은 화면에서 제거했습니다.
  • Smoke·Regression·Full QA의 범위, XP·방 카드 회귀 검증, Full 화면 녹화 및 권한 사전 점검을 갱신했습니다. 사용하지 않는 DuckDNS updater와 전용 QA 프로필도 제거했습니다.
  • Gradle 프로젝트 버전을 0.4.0-alpha에서 0.5.0-alpha로 변경했습니다.

0.4.0-alpha

역할 밸런스·첫 밤·완료 전적

5명·7명 역할표를 조정하고 첫 밤 진행과 계정 전적 저장을 추가했습니다.

인원수별 역할 밸런스

  • 4명: 마피아 1, 경찰 1, 의사 1, 시민 1 (변경 없음)
  • 5명: 마피아 1, 경찰 1, 의사 1, 시민 2. 기존 스파이를 시민 한 명으로 교체했습니다.
  • 6명: 마피아 1, 스파이 1, 경찰 1, 의사 1, 군인 1, 시민 1 (변경 없음)
  • 7명: 마피아 2, 경찰 1, 의사 1, 군인 1, 영매사 1, 시민 1. 기존 스파이를 영매사로 교체했습니다.
  • 8명: 마피아 2, 스파이 1, 경찰 1, 의사 1, 군인 1, 영매사 1, 시민 1 (변경 없음)
  • 접선하지 않은 스파이는 마피아 승리 동수 판정에서 제외합니다. 마피아팀이 모두 사망하면 시민팀이 승리합니다.

게임 진행·전적·재접속

  • 역할 확인이 끝나면 첫 밤으로 진행하고 밤 결과 뒤 낮 토론을 시작합니다.
  • 게임 종료 시 승리·패배와 총 게임 수를 계정에 한 번 기록하도록 완료 게임 테이블과 Flyway 마이그레이션을 추가했습니다. 이 버전에는 개별 경기 상세 이력 화면이 포함되지 않습니다.
  • 게임 중 마지막 연결이 끊긴 참가자에게 30초 재접속 유예를 적용했습니다. 방 설정 저장 결과도 설정 모달에서 확인할 수 있습니다.
  • QA 인원·재플레이·재접속·페이즈 시간 범위와 한국어 보고서 기록을 갱신했습니다.
  • Gradle 프로젝트 버전을 0.3.2-alpha에서 0.4.0-alpha로 변경했습니다.

0.3.2-alpha

동수 승리 판정·실시간 상태 안정화

마피아팀·시민팀 동수 판정과 방 상태의 동시 변경 경계를 보강했습니다.

  • 마피아팀 생존자 수가 시민팀과 같아지면 마피아팀 승리로 판정하되, 마피아팀 생존자가 0명이면 시민팀 승리를 우선합니다.
  • 방 입장·퇴장·빈 방 정리·방장 이전이 함께 진행될 때 상태가 엇갈리지 않도록 presence 처리와 예약 작업을 보강했습니다.
  • WebSocket 채팅 오류와 방 접근 예외 처리를 정리하고 관련 자동 검증을 보강했습니다.
  • Gradle 프로젝트 버전을 0.3.1-alpha에서 0.3.2-alpha로 변경했습니다.

0.3.1-alpha

도움말·프로필 통계·화면 정리
  • 게임방 도움말에 승리 규칙, 페이즈 순서·시간, 역할과 진영 설명을 추가했습니다.
  • 프로필 통계를 승률·마피아 승률에서 총 게임·승리·패배 수로 바꾸고, 당시 레이팅 기반 레벨을 표시했습니다. 현재는 XP 기반으로 대체됐습니다.
  • 게임 진행 패널, 참가자·채팅 영역과 대기방 설정 UI를 데스크톱·모바일 화면에 맞게 정리했습니다.
  • 화면 변경에 맞춰 QA 스크립트와 한글 보고서 기준을 갱신하고 버전을 0.3.1-alpha로 올렸습니다.

0.3.0-alpha

대기방 설정·종료 채널·패치노트
  • 방장이 대기 중인 방의 정원 4~8명과 비밀번호를 설정·변경·해제할 수 있고 서버도 같은 조건을 검증합니다.
  • 게임 종료 시 모두 전체 채널만 보거나 이용하도록 하고, 사망자의 종료 후 공개 메시지를 전체 채널로 전달합니다.
  • 경찰 조사 결과에는 상세 직업 대신 마피아팀·시민팀 진영을 표시합니다.
  • 메인 화면에 버전별 패치노트 상세 보기를 추가하고 Smoke·Regression·Full QA 범위 및 산출물 기준을 정리했습니다.
  • Gradle 프로젝트 버전을 0.2.0-alpha에서 0.3.0-alpha로 변경했습니다.

역할 확장·채널 권한·페이즈 안내

당시 역할 구성

  • 4명: 마피아 1, 경찰 1, 의사 1, 시민 1
  • 5명: 마피아 1, 스파이 1, 경찰 1, 의사 1, 시민 1
  • 6명: 마피아 1, 스파이 1, 경찰 1, 의사 1, 군인 1, 시민 1
  • 7명: 마피아 2, 스파이 1, 경찰 1, 의사 1, 군인 1, 시민 1
  • 8명: 마피아 2, 스파이 1, 경찰 1, 의사 1, 군인 1, 영매사 1, 시민 1
  • 5명·7명 역할표는 0.4.0-alpha에서 변경됐습니다.

역할·진행 규칙

  • 스파이는 밤에 직업을 조사해 마피아를 찾으면 접선하고 마피아 채널을 이용합니다. 직접 살해 행동은 하지 않습니다.
  • 군인은 마피아의 밤 공격을 한 번 막고, 영매사는 생존 중 사망자 채널을 이용하며 사망자의 직업을 조사할 수 있습니다.
  • 역할 확인 10초, 낮 토론 60초, 각 투표·최종 변론 15초, 밤 행동 30초를 적용했습니다.
  • 역할 행동·투표·마피아 및 사망자 채널 권한을 서버에서 확인하고 페이즈 안내, 재플레이·재접속 흐름과 QA를 보강했습니다.

0.1.1-alpha

시스템 안내·채팅 표시·기초 QA

  • WebSocket 권한·null 안정성, Java·JavaScript·Playwright 검증과 재사용 QA 문서를 보강했습니다.
  • Gradle 프로젝트 버전을 0.1.0-alpha에서 0.1.1-alpha로 변경했습니다.

0.1.0-alpha

초기 실시간 게임 MVP
  • 회원가입·로그인, 로비 방 검색·생성·입장, 4~8명 대기방과 방장·Ready 기능을 구현했습니다.
  • Spring WebSocket/STOMP로 방 상태와 채팅을 실시간 동기화합니다.
  • 마피아·경찰·의사·시민, 토론·투표·밤 행동, 서버 승패 판정과 역할 비공개 전달을 구성했습니다.
  • 게임 결과 후 재플레이와 새로고침·재접속 상태 복원을 지원하고 Java·JavaScript·다중 세션 E2E 기반을 마련했습니다.
